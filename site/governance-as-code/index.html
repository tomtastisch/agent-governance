Governance as Code

Agent Governance treats rules, contracts, and sources of truth as versioned artifacts — and verifies that documentation and tooling never drift from them.

Declarative sources of truth

The project keeps its policy, commands, discovery signals, and work-item classification in a closed, versioned bundle. Manifest and catalog references are validated fail-closed, so a dangling or unknown reference cannot be silently accepted.

Deterministic drift control

  • Version authority: a single VERSION source projected into package metadata and the changelog.
  • Command authority: the CLI command set is defined once and projected into the runtime and the reference.
  • Consistency gates: blocking checks detect documentation drift, competing version declarations, and stale document links before they merge.
  • Projection, not duplication: documentation and this website derive from, check against, or link to their authorities rather than maintaining independent copies.
