Governance-as-Code for AI Coding Agents

Agent Governance installs versioned, harness-agnostic rules for AI coding agents in a controlled, verifiable, and reversible way — and ships deterministic contracts for resume, work items, and sources of truth.

View on GitHub npm package Documentation

What it does

Agent Governance manages exactly its own Markdown block at an explicit global target path. It verifies a closed, versioned bundle, backs up the existing entry, and only mutates after explicit confirmation. The same installer is the source of truth for the CLI, while the package also exposes contract exports for resume state and work-item classification.

Verified install

A digest-bound bundle, explicit canonical paths, and a transactional install/verify lifecycle with rollback.

Resume contracts

Event-bound persistent checkpoints and a TOON codec for cross-session continuation.

Work-item classification

A declarative SSOT for work-item classification with deterministic GitHub-label projections.
