AI Coding Agent Governance

Apply the same versioned guardrails to every AI coding agent you run — without per-harness adapters or silent mutations.

The problem

AI coding agents (Codex, Claude Code, OpenCode, and others) read global instruction files that live at different paths on every harness. Ad-hoc edits drift, and implicit target assumptions can silently change an agent’s behavior.

How Agent Governance addresses it

  • Explicit paths: you choose the exact global target and entry file; the installer validates both and never guesses.
  • Passive discovery: setup pre-selects supported harnesses as editable defaults, then only mutates after your explicit confirmation.
  • Verified and reversible: a digest-bound bundle, backups, and a transactional rollback keep every change auditable.
  • Harness-agnostic: one rule set projected to multiple harnesses, with the normative source kept in a single versioned bundle.
